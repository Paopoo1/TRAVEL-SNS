# Trailbook
Browser prototype: index.html. Mobile prototype: mobile/ (Expo).
Browser data is local. Shared accounts, uploads, and shop permissions are future work.
Continue browser-first. Preserve the photo atlas, visit crowns, route recommendations, and shop workspace.

Browser UI: map-first feed with local sample photographs, category filters, saved cards, photo previews, and bottom navigation. Use the top-right selector for 8 UI languages. Routes, photo records and shops are in the expandable trip tools panel. Photos in the initial feed are labeled inspiration samples; they are not actual posts or photos of the selected area.
