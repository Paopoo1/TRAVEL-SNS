# Trailbook
Browser prototype: index.html. Mobile prototype: mobile/ (Expo).
Browser data is local. Shared accounts, uploads, and shop permissions are future work.
Continue browser-first. Preserve the photo atlas, visit crowns, route recommendations, and shop workspace.

Browser UI: map-first feed with local sample photographs, category filters, saved cards, photo previews, and bottom navigation. Use the top-right selector for 8 UI languages. Routes, photo records and shops are in the expandable trip tools panel. Photos in the initial feed are labeled inspiration samples; they are not actual posts or photos of the selected area. Photo credits: assets/PHOTO-CREDITS.md.

Personal atlas: tap the bottom-left icon for your profile, world overview, or saved area selection (Kyoto/Osaka/Tokyo). A recorded visit colors a place light blue; three distinct visit dates color it orange and add a crown. Multiple photos on the same date count as one visit day. Area regular badges use distinct dates across that area; spot badges use dates at that spot. The current regular list contains only the local profile, not shared user data. Maps are illustrative.

Map controls: use +/− (100–400%), reset, mouse wheel, touch pinch, and drag to pan. Map view is retained during in-page language/navigation changes. Focus the map for +/−, arrow-key panning, and Home to reset. Controls remain fixed while map content moves.
