Trailbook — iPhone / Android 試作

このフォルダで npm install を実行し、npx expo start で開発サーバーを起動します。
スマホを同じネットワークにつなぎ、SDK 58 対応の Expo Go または開発ビルドで起動します。
Expo Go の対応状況は https://docs.expo.dev/get-started/expo-go/ を参照してください。

試す流れ
1. エリアを選び、地図のスポットを選択して、訪問日と写真を登録します。
2. My Trips で写真を確認します。同じ場所で異なる訪問日が3日になると王冠が付きます。
3. 困りごとでサンプルの質問を開くか、自分で質問と回答を追加します。
4. イベント・お店でエリアをフォローします。情報とベルはサンプル表示です。
5. 地図の下からエリアを追加すると、そのエリアにも質問・回答を登録できます。

試作の範囲
写真、質問、回答、フォローはこの端末に保存します。
初期の旅ルート、イベント、店舗はサンプルです。地図は模式表示です。
月・火星は将来用の画面です。
端末間共有、ログイン、実在店舗の出店申請、プッシュ通知、動画は未実装です。
ストア配布用の署名済みアプリは作成していません。
